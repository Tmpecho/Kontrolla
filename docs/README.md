# Documentation

The documentation is now split by module:

- [`docs/frontend/`](./frontend/) for Vue frontend setup, system documentation, and test data
- [`docs/backend/`](./backend/) for Spring Boot backend setup, API documentation, system documentation, and test data

Recommended use:

- Use each module `README.md` as the quick-start guide for developers.
- Use each module `system-documentation.md` as the source document for PDF export.
- Use [`docs/backend/api.md`](./backend/api.md) together with Swagger at `http://localhost:8080/swagger-ui.html` for API documentation.
